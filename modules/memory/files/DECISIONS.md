# Decisions — lazy index

Record only decisions that cannot be derived from code. Keep one thematic file per durable subject
under `decisions/`, and add one pointer here. Do not preload every theme.

| Theme | File | Read when |
|---|---|---|

Decision format:

```text
YYYY-MM-DD — [scope] decision — reason — evidence
```

Append corrections as new decisions; never rewrite history. Keep this index below 32 KiB.
