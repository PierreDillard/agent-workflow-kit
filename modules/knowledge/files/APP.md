# Application flows — index

Code navigation map, separate from the domain facts in [DOC.md](DOC.md). One file per flow in
`doc/app/`. Find a keyword under "When to read", then open only that flow and its matching `## `
section. Do not load every flow. A flow links to its implementation files; rules and invariants
stay in their owning documents.

| Flow | File | When to read (keywords) |
|---|---|---|

Row format: flow name, a relative link to `doc/app/<flow>.md`, then the symbols, files and
symptoms that should lead a reader to that flow. Shape, budgets and splitting rules come from
the mandatory `doc-pattern` skill.
